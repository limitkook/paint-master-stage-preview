# Paint Master · 정원 웹 체험판

작성/수정: Hermes Agent · 2026-10-10 · 사용자의 창문 및 전체 구조 재검수 요청.

- 338칸/30색. Unity WebGL/APK가 아닌 동일 자산의 JS/Canvas 체험판.
- 창문7개: 돌 창틀, 연결 목재 창살, 각 유리 면을 원본 확대 좌표로 구분. 반사 얼룩은 별도 칸이 아니다. 유리의 번호는 해당 창틀/창살 번호와 겹치지 않도록 한다.
- 다리 기둥9부위, 난간/데크 큰 색면, 격자 목재와 뒤 잎, 문 구조를 구분. 나무와 잎/꽃은 질감 대신 큰 색 덩어리.
- 정면 벽3, 수면6, 큰 나무 잎25, 줄기5. 배경23연결 면은 색칠 가능. 과거7면은 작은 배경이 주변 영역에 흡수되던 상태다.
- 원본 PNG/전경 RGB 보존. 밝은 배경만 별도 파생채색본에서 아이보리 처리.
- 각 완료영역은 정확히 한 연결면. 최종 authored atlas 부모를 넘는 runtime 병합0. 단, 자동 후보 및 수동 구조 좌표는 원화 실루엣의 완전한 정밀추적을 보장하지 않는다.
- 붓/확대번호/놓은 뒤90%완료/owner-clipped광택 유지. 전체 이미지 면적 진행률, 캔버스 밖/오색 no-op.
- GitHub Pages main/root. 현재 manifest의 지역수/해시/캐시 버전을 함께 갱신한다. 스테이지 정적파일만 공개, 서버 서비스/포트 변경 없음.
