# Paint Master · 정원 스테이지 웹 체험판

작성/수정: Hermes Agent, 2026-10-10 KST. 사용자 승인 범위: 정원700칸 스테이지만 공개 웹 공유.

- Unity 프로젝트의 승인 원화/700칸 소유권/30색 데이터를 사용하는 별도 JavaScript/Canvas 체험판이다. Unity WebGL/APK 빌드가 아니다.
- 색 선택 후 직접 문질러 칠한다. 원화 RGB를 부분적으로 드러내며 정상 release에서90% 이상 칠한 해당 칸만 완성한다. 같은 번호의 다른 칸은 독립이다.
- 마우스 휠/＋− 확대, 우클릭 드래그 이동. 모바일 한 손가락 색칠, 두 손가락 이동/확대. 작은 번호는 더 확대해야 보인다.
- 새로고침하면 진행이 초기화된다. 서버 저장, 계정, 광고, 결제, 외부 분석 도구가 없다.
- 완료 광택/효과음/무지개 면적 진행률은 웹 구현이며 Unity 실행 검증을 뜻하지 않는다.
- 승인된 AI 생성 원화의 PNG bytes는 유지했다. 큰 객체 지도와 내부 색 경계는 근사이며 일부 잎·꽃 묶음과 래스터 경계가 남는다.
- 파일은 공개돼 누구나 다운로드할 수 있다. 전체 Unity 프로젝트/다른 스테이지/서버 설정/비밀값은 포함하지 않는다.

- 문 주변의 문짝/문틀/기둥/박공/처마/계단, 꽃 색 묶음과 나무 큰 명암을 보정했다. 붓의 선형 크기는 이전의 절반, 번호는2.2배 이상 확대와 더 큰 실제 내부 공간을 요구한다.
- 큰 끊긴 소유권 조각은 독립 완료 필드로 분리했다. 작은 질감 조각/일부 같은 꽃 묶음은 공유할 수 있다. 테두리는 최종 owner 격자에서 다시 만들며 그 격자가 실제 브러시 clip과 완료 범위의 정본이다.
- stage-manifest.json의 해시로 원화/guide/level을 함께 검사하고 해시별URL로 받아 오래된 guide와 새 소유권이 섞이지 않도록 한다.

공개 호스팅: GitHub Pages, main 브랜치 루트. Oracle 서버에는 웹 서비스/포트를 추가하지 않는다.
